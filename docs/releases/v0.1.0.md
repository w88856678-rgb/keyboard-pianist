# 键盘钢琴家 · 首个公开版本

**弹钢琴，何必需要一台钢琴。**

把熟悉的电脑键盘，变成自己的小琴房。选一首喜欢的歌，跟着歌词下方的字母提示敲键盘，就能弹出对应的旋律。

👉 [打开在线琴房](https://keyboard-pianist.pages.dev/)

这个版本可以：

- 跟歌弹奏：完整一句歌词一起看，字母与音名一一对应，弹完一段再进入下一段。
- 从熟悉的歌曲开始：《演员》《成都》等12首歌曲，以及2首原创练习。
- 自由弹奏：用26个字母探索旋律，支持多键和弦、延音与八度切换。
- 带上自己的乐谱：导入 MusicXML、MIDI、图片或 PDF，试听校对后加入个人曲库。
- 电脑和手机都能玩：电脑敲键盘，手机点按屏幕按键。

本仓库包含「沉浸舞台」界面。在线体验入口目前保留此前发布的琴房界面，GitHub 发布不会自动更新线上站点。

图片和 PDF 自动识谱会先生成初稿，复杂谱面需要校对。个人曲库保存在当前浏览器，重要曲谱记得导出备份。

欢迎在 [Issues](https://github.com/w88856678-rgb/keyboard-pianist/issues) 留下体验、问题或想弹的歌。如果喜欢，也欢迎把这个小琴房分享给朋友。
