# 曲库与导入说明

## 内置曲目

目前包含《演员》《成都》《告白气球》《小幸运》《后来》《十年》《好久不见》《往后余生》《追光者》《岁月神偷》（不才版）《纸短情长》《暖暖》，另有两首原创练习。

原谱来自 [Flame-shi/musical-notation](https://github.com/Flame-shi/musical-notation)，固定版本为 `d270cf5f912225d8e9ac016e8a7a2a0299204f56`。项目保留源图、版本与校对说明；在「曲谱管理 → 原谱与版本说明」或电脑端「查看原谱」可查看。

内置歌曲按所选谱面的反复和段落顺序展开，主要是单旋律钢琴音色演奏，并非原录音的全部声部。

- **演员**：B调旋律简谱，包含前奏、主歌、副歌、桥段、尾奏；原谱没有独立完整间奏或双手伴奏。
- **成都**：孟航制谱，D调、3/4，包含前奏、间奏、尾奏；合唱及童声段也使用钢琴音色。
- **其余十首**：保留各自原谱与校订说明，简化或补音以应用中的版本说明为准。

在线原谱目录索引124份文件，含分页与不同版本，不等于124首已转换歌曲。目录提供来源入口，可弹曲目会另行标识。

## 导入之后会发生什么

导入 → 选择声部或识谱 → 试听与校对 → 保存到当前浏览器曲库。

| 格式 | 能读取什么 | 需要留意什么 |
|---|---|---|
| MusicXML / XML / MXL | 音符、时值、歌词、和弦、休止及简单反复 | 只支持 `score-partwise`；复杂跳房子与 D.C./D.S. 可能需要手动整理 |
| MIDI | 音符、内嵌歌词、部分段落标记 | PPQ时间制；无歌词可补词，或按音符提示演奏；不完整还原整曲变速 |
| 图片 / PDF | 浏览器本机识谱后的可编辑初稿 | 清晰度、排版与反复会影响准确率；请先试听校对 |
| 曲谱 JSON | 本应用导出的曲谱数据 | 用于备份和迁移 |

PDF单文件最多12页、30 MB。可一次选择多个文件，逐首校对和保存；同曲分页建议先合并，避免被当作独立歌曲。首次图片识谱需要加载模型与运行资源，等待时间取决于网络和设备。

歌词可按完整句换行；一字多音可合并。前奏、间奏和尾奏可以标记为器乐段，保存后同样使用逐段指引。
